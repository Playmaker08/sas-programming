# Reproducibility Guide

## SAS

The SAS engine expects this home-directory layout:

```text
~/sas/
~/data/raw/
~/data/intermediate/
~/data/model/
~/outputs/
```

Copy all files from the repository `sas/` directory to `~/sas/`.

Place these official macro CSVs in `~/data/raw/`:
- `UNRATE.csv`
- `FEDFUNDS.csv`
- `GDP_REAL_GROWTH.csv`

Then run `run_all.sas`.

The synthetic engine uses a fixed seed (`9172026`). Results are deterministic conditional on the same SAS environment and macro input files.

## Python

```bash
python -m venv .venv
source .venv/bin/activate   # macOS/Linux
pip install -r requirements.txt
cp data/processed/p8_powerbi_account_fact.csv python/
cd python
python 19_python_challenger.py
python 20_python_risk_diagnostics.py
```

## Power BI

The processed CSVs under `data/processed/` are sufficient to recreate the four-page dashboard. Use `powerbi/BUILD_GUIDE.md` and `powerbi/DAX_MEASURES.md`.

The `.pbix` file is intentionally not generated by this repository build step. Copy your local final dashboard into `powerbi/IFRS9_Credit_Risk_ECL_Dashboard.pbix` before publishing the repository if you want the binary dashboard included.
